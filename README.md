## 常用命令备忘

```bash
git status              # 看当前有哪些改动
git add .               # 把所有改动加入暂存区
git commit -m "说明"     # 提交，说明写清楚改了什么
git push                # 推送到 GitHub
git pull                # 把 GitHub 上的改动拉回本地
```
